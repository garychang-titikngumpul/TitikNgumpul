# TitikNgumpul V4

Website publik + admin realtime berbasis Supabase.

## Sudah termasuk
- Public season selector
- Registrasi tim aktual / target registrasi
- Generic single-elimination bracket untuk 2–128 tim
- Admin login Supabase
- Create season
- Add/edit/delete teams
- Generate/rebuild bracket
- Edit scores and team names
- Realtime public updates via Supabase Realtime
- WhatsApp Community, Instagram, admin contacts
- Jersey catalog

## Deploy
Upload isi folder ini ke repository GitHub lalu connect repository tersebut ke project Vercel `titikngumpul`.

`config.js` sudah berisi Supabase Project URL dan publishable key yang diberikan user.
